## Installation

Build the Docker image by running:  

```bash
cd ChronoPoints
./build_docker.sh
```

After the build finishes, start the container and attach to it:
```bash
./run_docker.sh
```

The `run_docker.sh` script automatically runs `docker exec -it` after starting the container, placing you directly into an interactive terminal session inside the container.

## Training
To train the model from zero on the provided dataset, run:
```bash
cd src
python3 train_chrono_cls.py --num_frame 12 --seed 0
```
You can adjust the sequence length using the `num_frame` parameter.

To resume model training from a previous checkpoint run:
```bash
cd src
python3 train_chrono_cls.py --resume f{x}g{y}_seed_{z}_{run_date}
```
where `f{x}g{y}_seed_{z}_{run_date}` is the run directory in `src/output`, generated by a prior training from scratch.  
Example: `f12g1_seed_0_2026-04-22-11-32-06` 

## Evaluation
To evaluate a trained model, run:
```bash
cd src
python3 test_chrono_cls.py --run_dir f{x}g{y}_seed_{z}_{run_date}
```
where `f{x}g{y}_seed_{z}_{run_date}` is the run directory in `src/output`, generated by the training you wish to evaluate.  
Example: `f12g1_seed_0_2026-04-22-11-32-06`
